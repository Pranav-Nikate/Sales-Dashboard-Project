
# 📊 Sales Dashboard Project

## Overview
This project analyzes sales data using Excel, SQL, and Power BI.

## Tools Used
- Microsoft Excel
- MySQL
- Power BI

## Dataset
The dataset contains:
- Order ID
- Order Date
- Customer Name
- City
- Product
- Category
- Quantity
- Unit Price
- Sales
- Payment Method

## SQL Analysis
The SQL queries include:
- Total Sales
- Monthly Sales
- Top Customers
- Sales by Category
- Sales by City

## Power BI Dashboard
The dashboard contains:
- KPI Cards
- Monthly Sales Trend
- Sales by Category
- Sales by City
- Top Customers
- Payment Method Analysis
- Slicers
